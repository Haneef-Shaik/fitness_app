## What this record is for

DS-6 box 1 asks for "the assets are generated by script into `apps/mobile/assets/`, and the owner's
approval is recorded". Under tracker decision **AUTH-01**, the owner delegated routine product and
visual decisions to Codex, the coordinating agent. AUTH-01 also says that "the delegation decides; it
does not create evidence". An approval entered here must therefore name its real authority and the
exact files it approves.

This record covers the **visual approval of the art only**. It is **not** trademark clearance of the
name. That is DS-6 box 2 (DEC-01). It needs a dated search and a qualified clearance, and neither
Codex nor the generator can supply it (see [brand-clearance.md](brand-clearance.md)).

## Before approving

1. Run `rtk node --test apps/mobile/scripts/store-art/tests/*.test.mjs`. All tests must pass.
2. Run `rtk node apps/mobile/scripts/store-art/generate.mjs`, then
   `rtk node apps/mobile/scripts/store-art/generate.mjs --check`. It must print "matches".
3. Look at every PNG in `apps/mobile/assets/store-art/` at full size and at launcher size, on both dark
   and light backgrounds. The design intent is in [art-direction.md](art-direction.md).
4. Copy the sha256 of `manifest.json` below. Approving that hash approves exactly the files it lists.
