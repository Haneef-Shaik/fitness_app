## How, in this repo

### The resolution rule is already written

From [PRD §7.2](../01-PRD.md): the most recent **`completed`** session containing an exercise whose
`exercise_muscles` row is that group **or a descendant** with `role = 'primary'`, ordered by
`completed_at DESC`. **If nothing matches, widen to `('primary','secondary')` — and the UI must say
it widened.**

The muscle tree is self-referencing, so "or a descendant" is a **recursive CTE**. Write it **once**,
give it a name, and **test it against a grandchild group** — a two-level test passes for a
one-level-only implementation. G6 shares this CTE for muscle volume; build it to be shared.

### AC-03 is a unit matrix, not an E2E

Sessions started at **23:40 across ≥5 timezones including both DST directions**, asserted against
the `local_date` vectors already in `contracts/vectors/domain.json`. This goal **consumes** those
vectors rather than inventing new ones — inventing new ones is how two definitions of a day appear.

### Cursor pagination — settle the shape here

Opaque cursor over `(started_at, id)`. Every list endpoint after this one copies it, so write down
the shape in [`docs/02-SYSTEM-ARCHITECTURE.md`](../02-SYSTEM-ARCHITECTURE.md) as the convention, not
just the code.

**Not offset.** History grows and offsets drift under inserts — a user paging back through their
sessions while a sync lands sees a row twice or never.

### The widen must be visible

If the answer came from a widened search, the response says so and **F-0x renders it in words**.
Widening silently is worse than returning nothing: the user believes they trained a muscle group
they did not.

## Invariants you must not break

- **I7 — the day is the profile's day.** `to_local_date(instant, tz)` is the only route to a date.
  No screen and no SQL computes its own.
- **I1 — the plan tree is not the performed tree.** History reads performed rows only.
- **I3 — warm-ups excluded from volume and PRs** (D6) — history's summaries obey it.
- **I13 — filtered-empty ≠ genuinely empty.** A history filtered to "Chest, last 30 days" with no
  matches is not a user with no history.
- **I9 — one envelope, always.** Cursor metadata lives inside it.

## Traps — written before you hit them

- **Widening silently.** The single most damaging bug available in this goal.
- **Paginating by offset.** It works in a demo and drifts in real use.
- Testing the CTE one level deep. A one-level implementation passes a one-level test.
- Writing new timezone vectors instead of consuming the existing ones — two sources, one drift.
- Treating `cancelled` sessions as history. D-status rules: cancelled rows are retained and appear
  in neither history nor analytics.
