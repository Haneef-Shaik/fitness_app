logger's numbers**. **AC-06** is exactly that agreement: the same session's numbers match on the

## How, in this repo

### Never re-derive a number in SQL

Every number here already has a definition in `app/domain/training.py` and a vector in
`contracts/`. **Do not re-derive any of them in a SQL aggregate** — that is precisely how AC-06's
"matching across all three screens" fails, and it fails quietly, months later, on one user's data.

Where an aggregate genuinely **must** run in SQL for performance, add a test that asserts **the SQL
result equals the domain function over the same rows**. That test is the price of the aggregate.

### Muscle volume

**Primary ×1.0, secondary ×0.5** (D7), and it must recurse the group tree **exactly as G5's rule
does**. Share the CTE — if it is not shareable, make it shareable here rather than copying it.

### Charts — the design system is normative

From [05 §3](../05-DESIGN-SYSTEM.md):

- **Fixed series order, never cycled.** Colour follows the **entity**, never its rank.
- **Slot 7 is a spacer and is not assignable** — the assignable ceiling is **6** series.
- **One axis, never two.**
- **Legend always present for ≥2 series.**
- **A regression is never red.** A lighter week is information, not an error (**I11**).

Build these as a **chart kit** (`H6.1`) — palette, axis, tooltip, empty state — because G9's
dashboard and G7's nutrition trends consume it. A chart built inside G-02 is a chart built twice.

### Performance

The analytics read model must **not scan every set on every request**. Where that means a
materialised summary or an index, add it as a migration with `alembic check` clean and a reversible
downgrade, the same discipline as the three existing migrations.

## Invariants you must not break

- **I3 — warm-ups are excluded from volume and PRs** (D6). Every aggregate filters them.
- **I4 — muscle volume: primary ×1.0, secondary ×0.5** (D7).
- **I5 — Epley, stored as `epley_v1`.** The version travels with the value; a chart mixing formula
  versions is silently wrong.
- **I6 — canonical units in storage**; convert only at the display edge.
- **I7 — the day is the profile's day.** Weekly and monthly buckets are built from local dates.
- **I11 — a regression is never red.**
- **I13 — filtered-empty ≠ genuinely empty.**

## Traps — written before you hit them

- **A second definition of volume living in SQL.** The whole goal in one sentence.
- **Cycling chart colours when a filter changes the series count.** Colour follows the entity, never
  its rank — a user filtering one exercise out must not see every other line change colour.
- Plotting e1RM across sets computed with different `formula_version` values as one series.
- An "adherence" number invented here instead of taken from its definition. If it has no definition
  yet, write one **in the domain module with a vector**, then chart it.
- Loading every set into memory to compute a year of volume and calling it fast because the seed
  data is small.
