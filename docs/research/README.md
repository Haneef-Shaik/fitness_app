# Research and validation evidence

This directory is intentionally empty after the 11 October 2026 documentation reset. The prior
market, competitor and implementation research described a removed codebase or older product
directions and was deleted to avoid steering new work incorrectly.

Use this directory only for new, locally stored evidence produced for the current PRD and plan:
pilot interview notes, counsel-approved guidance, food-AI accuracy runs, licence checks and
go/no-go memos. Every evidence file must name the relevant PRD requirement and goal ID.
